市场生命周期模型

polyData 将 Polymarket market 视为一个生命周期对象，而不是静态表行。生命周期从 Gamma、CLOB 或链上 TokenRegistered 事件发现市场开始；当 condition id 和 CLOB token id 可用时变为可交易；当价格、BBO、成交量或 OrderFilled flow 出现时进入 active 状态。

结算阶段

当 end date 到达或交易标记关闭时，市场进入 closing；当匹配到 UMA request、proposal、dispute 或 settlement 事件时进入 oracle review；当最终状态和结算结果已知后变为 resolved，随后进入 archived，但仍可查询。
