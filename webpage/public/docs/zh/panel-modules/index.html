Panel 注册表

当前仪表盘注册了 68 个 panels。它们被拆分为小型前端模块，具有明确的 metadata、fetch 行为和 renderer；runtime panels 还拥有后端 registry entry 和 snapshot route。

Panel 覆盖范围

核心 market、chain、oracle、AI、finance、crypto、macro、weather、sports 和 time panels 为仪表盘提供独立视图，用于发现、上下文、流动、结算风险和外部催化因素。
